# Aether AI | Next-Gen Fintech Landing Page

A premium, "Studio-Style" landing page for a fictional AI-powered Fintech startup. Built with modern web technologies and focused on high-end animations and dark mode aesthetics.

![Aether AI Hero](assets/hero-bg.png)

## ✨ Features
- **High-End GSAP Animations**: Smooth entrance reveals, mouse parallax, and floating background elements.
- **Bento Grid Layout**: Modern feature showcase for high conversion.
- **Premium Dark Mode**: Deep black aesthetic with neon cyan and purple accents.
- **Waitlist Integration**: AJAX-based form submission with PHP backend and JSON storage.
- **Interactive UI**: Custom fluid cursor and hover effects.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript
- **Animations**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger, TextPlugin)
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **Backend**: PHP (Waitlist handling)
- **Storage**: JSON (leads storage)

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/divyarajsinhgohil/aether-ai-landing-page.git
   ```
2. Move the files to your local server (e.g., XAMPP `htdocs`).
3. Open the project in your browser: `http://localhost/aether-ai-landing-page/index.php`.
